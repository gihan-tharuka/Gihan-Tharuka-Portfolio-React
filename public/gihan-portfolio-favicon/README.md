# Gihan Tharuka Portfolio Favicons

Theme:
- Background: black `#000000`
- Accent: orange `#FF7F01`
- Mark: `GT`

## How to use in a Next.js / React portfolio

1. Copy this whole `favicons` folder into your `public` folder.

Recommended path:

```txt
public/favicons/
```

2. Add these tags inside your `<head>` or Next.js metadata setup:

```html
<link rel="icon" href="/favicons/favicon.ico" sizes="any" />
<link rel="icon" href="/favicons/favicon.svg" type="image/svg+xml" />
<link rel="apple-touch-icon" href="/favicons/apple-touch-icon.png" />
<link rel="manifest" href="/favicons/site.webmanifest" />
<meta name="theme-color" content="#FF7F01" />
<meta name="msapplication-TileColor" content="#000000" />
<meta name="msapplication-config" content="/favicons/browserconfig.xml" />
```
